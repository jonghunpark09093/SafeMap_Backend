# SafeMap 페르소나 가중치 근거 정리

> 종로구 안심 보행경로 추천에서 사용하는 **페르소나별 위험지표 가중치(wᵢ)** 의 설계 근거 문서.
> 발표·논문 방어용. 본 문서의 학술/정책/표준 출처는 **실재하는 자료**만 인용했으며,
> 정확한 고시번호·페이지·수치는 최종 제출 전 원문에서 재확인할 것(아래 §6 참고).

---

## 1. 비용 모델 개요

경로 탐색은 pgRouting의 다익스트라(Dijkstra)로 수행하며, 각 도로 구간(edge)의 통행 비용은
**거리에 위험 가중을 곱한 형태**다.

```
Cost = Length × ( 1 + Σ wᵢ · Rᵢ )      (i = security, led, sdot, slope, civil, flow)
```

- `Rᵢ` : 지표 i의 위험도. **0~1로 정규화**(1에 가까울수록 위험).
- `wᵢ` : **페르소나별 가중치**. 위험을 얼마나 “멀게(=비싸게)” 느끼는지를 정함.
- `(1 + …)` 구조이므로, 위험이 0이면 비용은 순수 거리와 같고, 위험이 커질수록
  실제 거리보다 “체감 거리”가 길어져 우회를 유도한다.

구간 위험도(시각화용)는 가중 평균으로 정규화한다.

```
edge_risk = ( Σ wᵢ · Rᵢ ) / ( Σ wᵢ )
```

`edge_risk` 임계값으로 4단계 색상 분절(코드 기준):

| 단계 | 조건 | 색 |
|---|---|---|
| safe(안전)    | `edge_risk < 0.52` | 초록 |
| caution(주의) | `< 0.64` | 노랑 |
| warning(경고) | `< 0.78` | 주황 |
| danger(위험)  | `이상` | 빨강 |

## 2. 6대 위험지표 정의 및 데이터 출처

| 코드 | 지표 | 의미 | 데이터 성격 |
|---|---|---|---|
| `security` | 치안 | 범죄 취약/감시 부재(예: CCTV 미설치 구역) | 정적(공간) |
| `led` | 인프라 조도 | 가로등 등 조명 인프라 밀도 | 정적(공간) |
| `sdot` | 실측 조도 | S-DoT 도시데이터센서의 **시간대별 조도** | **동적(시간대)** |
| `slope` | 경사도 | 보행로 종단/지형 경사 | 정적(지형) |
| `civil` | 민원/위험물 | 도로 파손·공사 등 생활안전 민원 빅데이터 | 정적(누적) |
| `flow` | 유동인구 | 보행 통행량(자연감시 대리지표) | 정적/준동적 |

> `sdot`은 `request_hour` 파라미터로 시간대별 센서값을 LEFT JOIN하여
> **밤에는 어두운 길의 위험을 동적으로 키우는** 핵심 축이다. 센서 결측 시 기본값 0.5.

## 3. 가중치 설정 원칙

1. **상대적 우선순위**: 가중치 숫자(예: 2.5, 5.0)는 절대적 물리량이 아니라,
   해당 페르소나가 지표 간 위험을 **상대적으로 얼마나 더 중시하는지**를 나타낸다.
   (general의 모든 값 1.0을 기준선으로 둔 배수)
2. **휴리스틱 + 사후 검증 가능**: 1차 가중치는 선행 이론·정책·표준에 근거한
   **전문가 판단(heuristic)** 으로 설정했다. 향후 **AHP(계층분석법, Analytic Hierarchy
   Process)** 쌍대비교 설문으로 동일 구조를 **정량 검증**할 수 있도록 설계되어 있다.
   *(주의: 현 단계에서 AHP 설문을 실제 수행하지는 않았다. 방어 시 “정량 검증 가능한
   구조”로 설명할 것.)*
3. **기준선(general)**: 일반 보행자는 6개 지표를 균등(1.0)하게 둬, 다른 페르소나의
   강조를 비교하는 **대조군** 역할을 한다.

## 4. 페르소나별 가중치 및 근거

### 4.1 가중치 표 (코드 기준)

| 지표 | general | women | senior | 비고 |
|---|:--:|:--:|:--:|---|
| security | 1.0 | **2.5** | 1.0 | 범죄 취약성 |
| led      | 1.0 | 1.5 | 1.2 | 조명 인프라 |
| sdot     | 1.0 | **2.2** | 1.2 | 실측 조도(야간) |
| slope    | 1.0 | 1.0 | **5.0** | 경사/낙상 |
| civil    | 1.0 | 1.2 | 1.5 | 노면·공사 |
| flow     | 1.0 | 1.8 | 1.0 | 유동인구(자연감시) |

### 4.2 일반(general) — 균등 기준선
- 특정 취약성을 가정하지 않는 표준 보행자. 모든 지표 1.0.
- 역할: 페르소나별 우회 효과를 비교하기 위한 **baseline**.

### 4.3 여성(women) — 범죄·체감 안전 우선
핵심 가설: *야간·인적 드문·어두운 구간에서의 범죄 취약성*이 가장 큰 위협.

- **security 2.5 / sdot 2.2 / flow 1.8 (최상위 3종)**
  - **CPTED(환경설계를 통한 범죄예방)** 의 핵심 원리인 **자연감시(natural surveillance)**
    와 **감시장치**에 직접 대응: 밝은 조도(sdot/led), 감시(CCTV=security),
    사람 통행(flow)이 많을수록 범죄 기회가 감소.
  - **서울시 여성안심 정책**(여성안심귀갓길, 안심이 앱·비상벨, 안심 CCTV)이
    *밝고·CCTV 있고·사람이 다니는 길*을 우선하는 설계 철학과 일치.
- **led 1.5**: 조명 인프라 보강 효과. sdot(실측)과 함께 야간 시인성 축.
- **civil 1.2 / slope 1.0**: 범죄 위협 대비 상대적 후순위(slope는 기준선 유지).

### 4.4 노약자(senior) — 이동성·낙상 위험 우선
핵심 가설: *급경사·노면 결함으로 인한 낙상과 체력 소모*가 가장 큰 위협.

- **slope 5.0 (압도적 1순위)**
  - **「장애인·노인·임산부 등의 편의증진 보장에 관한 법률」** 및 **BF(Barrier Free)
    인증** 기준에서 보행 접근로의 **기울기 상한**(완만한 경사 권장)을 규정 → 급경사
    회피가 보행약자 설계의 1원칙.
  - **국토교통부 「보도 설치 및 관리 지침」** 의 보도 종단경사 기준과 부합.
  - 고령자 보행안전·낙상 위험 문헌에서 경사·노면이 주요 위험요인으로 지목.
- **civil 1.5**: 도로 파손·요철·공사 등 노면 결함 회피(보행 안정성).
- **led 1.2 / sdot 1.2**: 야간 시인성 저하 시 낙상 위험 증가 → 조도 보조 가중.
- **security 1.0 / flow 1.0**: 범죄보다 물리적 이동성 위험을 우선하므로 기준선 유지.

---

## 5. 시간대 동적성 (보강 포인트)
- `sdot`(실측 조도)는 `request_hour`로 시간대별 센서값을 반영하므로,
  **동일 경로라도 주간/야간 결과가 달라진다.** 이는 “정적 안전지도”와 차별화되는
  본 서비스의 핵심 기여로, women의 sdot/led 가중과 결합해 **야간 우회**를 강화한다.

## 6. 인용 출처 (실제 확인본)
아래는 **웹에서 1차 확인한 실재 출처**다. 발표·논문 각주에 그대로 쓸 수 있도록
정확한 명칭·핵심 수치·연도를 함께 정리했다. (최종 제출 전 고시번호·페이지만 원문에서 재확인)

### 6.1 slope(경사) 근거 — 보행약자 접근로 기울기
- **「장애인·노인·임산부 등의 편의증진 보장에 관한 법률 시행규칙」 별표1**
  - 접근로 **종단(진행방향) 기울기 1/18 이하**(부득이한 경우 1/12까지 완화),
    **횡단 기울기 1/25 이하**, 바닥 **단차 2cm 이하**, **유효폭 1.2m 이상**,
    경사로가 길어지면 **30m마다 1.5m×1.5m 수평참** 설치.
  - → senior `slope` 가중을 압도적 1순위(5.0)로 둔 직접 근거. *"경사 회피 = 보행약자 1원칙"*.
  - 출처: 국가법령정보센터 시행규칙 별표 / 한국장애인개발원(KODDI) BF 인증 매뉴얼.
- **BF(Barrier Free, 장애물 없는 생활환경) 인증** 평가지표도 동일한 접근로 기울기·단차 기준을 사용.

### 6.2 security/flow/sdot 근거 — CPTED(범죄예방 환경설계)
- **국토교통부 「범죄예방 건축기준 고시」** (건축법에 2014년 범죄예방 기준 도입 후 운영)
  - 5대 원리: **자연감시 / 접근통제 / 영역성 강화 / 활동 활성화 / 유지관리**.
  - **자연감시 = 사각지대 최소화 + 야간 적절한 조도 확보**, **감시장치(CCTV)·조명** 명시.
  - → women의 `security`(CCTV·감시) / `flow`(자연감시·활동) / `sdot`·`led`(야간 조도) 가중의 이론적 토대.
  - 출처: 국가법령정보센터 「범죄예방 건축기준」 고시 / 건축공간연구원(AURI) CPTED 가이드라인 / 경찰청·cpted.kr.

### 6.3 led/sdot 근거 — 조도(밝기) 표준
- **표준 선택(정정 완료)**: 보행/도로 조도는 흔히 잘못 인용되는 **KS A 3011(옥내 조도기준)** 이 아니라
  **「도로의 구조·시설 기준에 관한 규칙」 + 국토부 「도로안전시설 설치 및 관리 지침(제2편 조명시설)」**
  이 정확한 근거다. (KS A 3011은 사무실·복도 등 *실내* 권장 조도 위주라 보도 적용은 한계가 있음.)
- **확인된 권장 조도(lx)** — senior(낙상 시인성)·women(야간 범죄) 가중의 정량 근거:
  - **보행자 구역**: 가시성·방범 위해 통상 **30 lx 이상** 권장.
  - **횡단보도 평균 연직면 조도**(연속조명 구간): 상업지역 **20~30 lx**, 주거·공업지역 **10~20 lx**,
    기타지역 **10~15 lx**. (도로조명이 횡단보도 전후 50m에서 평균 30lx 초과 시 별도 횡단보도등 생략 가능.)
  - → "야간 조도↑ → 범죄·낙상 위험↓"의 **방향성**은 CPTED(§6.2)로, **구체 lux 수치**는 위 도로조명 기준으로 이중 근거화.
- (참고: 터널·지하차도는 **KS C 3703**이 별도 적용.)

### 6.4 서울시 여성안심 정책 (정책적 정합성)
- **여성안심귀갓길**, **안심이 앱(스마트 안전귀가)·비상벨**, **안심 CCTV** 사업.
  → *밝고·CCTV 있고·사람이 다니는 길* 우선이라는 women 페르소나 설계 철학과 일치.
  (서울시·자치구 공식 사업 페이지에서 사업 개요·연도 확인 후 인용)

### 6.5 senior 보강 문헌
- [ ] 고령자 보행안전·낙상 위험요인(경사·노면 결함) 학술문헌 1~2편 — 제출 전 1편 확정해 각주.

> **인용 원칙**: 위 항목은 실재 자료이나, 발표 슬라이드에는 **고시번호·시행일·페이지**까지
> 원문에서 한 번 더 확인해 각주로 달 것. 수치를 외워 옮기지 말고 원문 캡처를 부록에 첨부 권장.

## 7. 한계 및 향후 과제
- 가중치는 전문가 판단 기반 **상대값**이며, **AHP 쌍대비교 설문**으로 정량화·검증 시
  객관성 강화 가능.
- **가중치 민감도 분석**(±변화에 따른 경로 변화)으로 강건성을 추가 입증 가능.
- 사용자 제보(`user_reports`)는 신뢰도 이슈로 **위험도 계산에는 미반영**(별도 참고
  레이어). 향후 검증된 제보를 가중치에 반영하는 파이프라인은 별도 과제.
